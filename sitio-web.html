Conceptos de la Red

  • Página Web: Un documento electrónico digital programado en código que contiene los datos multimedia básicos.
  • Sitio Web: El grupo completo de páginas web conectadas entre sí que forman un espacio completo bajo un mismo enlace o dominio.

🌍 ¿Cómo viaja la información por Internet?

Al pulsar un enlace o escribir una URL en la barra de direcciones, se activa un intercambio de datos instantáneo estructurado en las siguientes fases de comunicación:

1. Servidores y Clientes

Tu equipo actúa de Cliente enviando una señal de solicitud. El computador a miles de kilómetros que guarda los archivos procesa la petición y actúa de Servidor respondiendo de vuelta.

2. Dirección IP y DNS

Cada máquina conectada posee una Dirección IP (código numérico identificativo). Los sistemas DNS actúan como traductores mapeando los nombres de dominios comunes a las IPs reales de los servidores.

3. Protocolos HTTP y HTTPS

Es la normativa de lenguaje que usan los equipos. HTTP transfiere los datos básicos del sitio web, mientras que HTTPS añade un certificado criptográfico seguro que viaja cifrado para proteger contraseñas y privacidad.

4. Transferencia de Datos

Toda la información digital se rompe en millones de pequeños paquetes de datos que toman caminos diferentes por routers y cables submarinos, volviéndose a agrupar en tu navegador de forma perfecta.
