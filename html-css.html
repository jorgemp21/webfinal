🏗️ Explicación de Etiquetas HTML

HTML se compone de etiquetas estructuradas anidadas que dan forma e indican al navegador cómo renderizar la información base:

<html> : Etiqueta contenedora donde nace toda la raíz de la web.
<head> : Zona técnica invisible que conecta metadatos y hojas de diseño.
<body> : Bloque que almacena todos los textos y partes visuales visibles.
<h1> a <h6> : Encabezados jerárquicos estructurados por orden de valor.
<p> : La etiqueta estándar empleada para dividir párrafos de contenido.
<img> : Código encargado de empotrar imágenes de forma organizada.
<a> : Ancla hipervínculo indispensable que enlaza varios archivos web.
<ul> y <li> : Contenedores para agrupar listas de elementos con viñetas.

🎨 ¿Qué es CSS?

CSS (Hojas de Estilo en Cascada) es el lenguaje informático de diseño que se encarga de interceptar el esqueleto plano de etiquetas generado por HTML para dotarlo de una capa estética profesional.

A través de CSS, los desarrolladores controlamos de forma unificada la apariencia global de un sitio: la distribución del espacio, los colores de contraste, las cajas translúcidas y los efectos interactivos que enriquecen la navegación de los usuarios.
